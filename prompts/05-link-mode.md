# Prompt B — Mode « relier » explicite

Dans le projet plans réseau, le fait de créer un câble via Alt+clic n'est pas découvrable et peut être capté par l'OS sur Mac/trackpad. Remplace-le par un mode « relier » explicite :

- Un bouton/outil dans la barre ou la palette active le mode « relier ».
- En mode relier, cliquer un premier nœud puis un second crée le câble ; un retour visuel montre le nœud source et le lien en cours de tracé.
- Échap ou clic dans le vide annule. Le mode reste actif pour enchaîner plusieurs liens, avec un moyen clair d'en sortir.
- Garde Alt+clic en raccourci optionnel, mais le mode explicite est le chemin principal.

Ne casse pas le déplacement/sélection existants. Montre-moi le changement d'UX avant de coder.
