# Prompt H — Panneau de propriétés + édition des équipements

Dans le projet plans réseau, ajoute un panneau de propriétés latéral qui s'ouvre quand je sélectionne un équipement (nœud).

- Éditer : le nom, le type, et les champs réseau (voir prompt suivant sur les IP).
- Le panneau se met à jour selon la sélection ; s'il n'y a rien de sélectionné, il est vide ou masqué.
- Le renommage doit rester répercuté partout (canvas, export, sauvegarde).

Garde le modèle compatible. Ne casse pas la multi-sélection : précise ce que le panneau affiche quand plusieurs éléments sont sélectionnés (par ex. édition commune ou message). Explique ton approche avant de coder.
